# Vox Box FX

A live voice FX deck that runs in the browser: phaser, tape echo, ping-pong delay, reverb and a granular time stretcher, with recording and a panic button.

## Run it

Browsers only allow the microphone on `https://` or `localhost`.

- **On your computer:** `python3 -m http.server 8791` in this folder, then open http://localhost:8791
- **On your phone:** host the folder over https (GitHub Pages, or drag it onto https://app.netlify.com/drop) and open that link.

Use headphones so the speakers don't feed back into the mic. Wired headphones have less lag than Bluetooth.

## Keys

`1`–`4` toggle effects · hold `Space` to grab for the stretcher · `Esc` panic · double-click a knob to reset
